# HawOptimizer
A script collection designed to speed up and clean your Windows computer.

# ⚠️ README ⚠️

**This project is back under active support.** However, please read the following carefully before proceeding:

- **No tutorial is provided.** You are expected to read and understand what each script does before running it.
- **No support will be given.** If something breaks, you are on your own. Do not open issues asking for help.
- **Use at your own risk.** Some scripts make deep system changes that can be irreversible. I am not responsible for any damage caused.

# How do I use it?
1. Go to the **Releases** page and download the latest `.zip`
2. Extract the archive
3. **Read each script** before running it, and understand what it does
4. Run the scripts you want **as Administrator**
5. Once done, **reboot Windows**


## What Does This Tweak?
- Telemetry & privacy settings
- System latency & responsiveness
- Unnecessary background services
- Windows bloatware
- And more, please check each script individually
